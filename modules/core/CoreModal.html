🔗 Documentation API REST v2.0

GET /exec - Obtenir le statut du système

GET https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=status&apiKey=YOUR_API_KEY

Retourne l'état opérationnel du système

GET /exec - Obtenir les métriques temps réel

GET https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=metriques&apiKey=YOUR_API_KEY

Retourne toutes les métriques du système

GET /exec - Lister les projets

GET https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=projets&apiKey=YOUR_API_KEY

Retourne la liste de tous les projets

POST /exec - Créer un backup

POST https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=backup&apiKey=YOUR_API_KEY

Crée un backup incrémental du système

GET /exec - Statistiques du cache

GET https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec?action=cache&apiKey=YOUR_API_KEY

Retourne les statistiques du cache
